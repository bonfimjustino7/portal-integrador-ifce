# Sistema para Elaboração de Horários dos Professores do IFCE Campus Cedro
Sistema para a disciplina de Projeto Integrador II

## Instuções para rodar a aplicação
- git clone no repositório `https://github.com/Andre-nemesis/Sistema-para-Elaboracao-de-Horarios-dos-Professores.git`
- excute o comando `npm run install all`
- e em seguida o comando `npm start` para executar simultâneamente a api e o front
- para rodar apenas a api execute o comando `npm run server`
- para rodar apenas o front execute o comando `npm run client`
- cada pasta `client` e `server` são projetos node suportando os comandos `npm` e `npx`

## Padrões de Commit
Para ficar mais profissional, seria bom a utilização de padrões ao realizar o commit, assim como a criação de arquivos e de mensagens de commits em **Inglês**
- `add: message` (ao relizar alguma adição ao código existente)
- `fix: message` (ao solucionar algum bug ou erro no código existente)
- `feat: message` (ao adicionar novas funcionalidades em massa no código existente, sendo considerado uma feature(versão do sistema))
- `up: message` (atualização de algum trecho do código existente)
- `delete: message` (exclusão de arquivos ou diretórios)
